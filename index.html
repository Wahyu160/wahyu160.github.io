01 / Tentang Saya

Mengenal saya
lebih dekat.

Saya merupakan lulusan Teknik Informatika dengan IPK 3,77 dan memiliki ketertarikan pada bidang Data Analytics serta pengolahan data. Saya mempelajari proses pengumpulan, pembersihan, pengolahan, analisis, dan visualisasi data menggunakan Python, SQL, dan Microsoft Excel.

Saya memahami dasar-dasar statistik deskriptif dan Exploratory Data Analysis (EDA), serta pernah mengembangkan dashboard interaktif menggunakan Streamlit. Melalui pengalaman magang dalam pengolahan data penjualan, saya memperoleh pengalaman menyusun rekapitulasi data untuk mendukung pemantauan aktivitas operasional.
