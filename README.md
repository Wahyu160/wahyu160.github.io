# Portofolio Wahyu Dwi Prakoso — Data Analyst

Website portofolio statis menggunakan HTML, Tailwind CSS (CDN), dan JavaScript.

## Menjalankan secara lokal
1. Ekstrak folder proyek.
2. Buka `index.html` di browser.
3. Koneksi internet diperlukan untuk memuat Tailwind CSS dan Google Fonts melalui CDN.

## Personalisasi sebelum dipublikasikan
Buka `index.html`, lalu:
- Informasi kontak, tautan LinkedIn, GitHub, perusahaan magang, periode magang, dan skor TOEIC sudah diisi berdasarkan data yang diberikan.
- Perbarui tautan proyek yang saat ini masih `#` dengan URL GitHub/demo yang benar.
- Lengkapi nama resmi, tanggal, dan tautan sertifikat pelatihan yang belum dicantumkan.
- Pastikan seluruh deskripsi proyek menggambarkan pekerjaan yang benar-benar telah dilakukan.

## Publikasi
### GitHub Pages
1. Buat repository GitHub baru.
2. Unggah `index.html`.
3. Buka Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/root`, lalu Save.

### Vercel
1. Unggah folder proyek ke repository GitHub.
2. Impor repository tersebut di Vercel.
3. Untuk website statis ini tidak diperlukan build command; output directory dapat menggunakan root (`.`).

## Catatan
Website ini merupakan template awal. Kartu proyek, tautan, data kontak, nama resmi, tanggal, dan tautan sertifikat pelatihan yang belum dicantumkan perlu diverifikasi serta dilengkapi sebelum dipakai untuk melamar pekerjaan.
